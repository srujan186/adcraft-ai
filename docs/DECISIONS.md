# Decisions — demo-readiness fix plan

Where the fix plan was silent, the simplest option was taken and recorded here
(`YYYY-MM-DD — decision — reason`). Earlier platform decisions: `ctv-platform-spec/docs/DECISIONS.md`.

2026-10-13 — `ENV` defaults to `production` — a deploy that forgets to set it must fail closed (dev routes and docs hidden); local `.env`, compose and tests set `development`.
2026-10-13 — API-key scopes are `read` (GET/HEAD/OPTIONS) and `write` (everything else); default `read`; an explicit empty list is rejected — least privilege. The "events" scope from task 14 is deferred: no API-key event-ingestion endpoint exists yet.
2026-10-13 — Keys stored with no scopes (created before enforcement) keep full access — they had it when issued; breaking existing integrations silently is worse.
2026-10-13 — Unbuilt settings screens are hidden by `NEXT_PUBLIC_SHOW_UNFINISHED` (off by default) and answer HTTP 404 via a `next.config` rewrite — `notFound()` inside the page rendered the 404 screen but with status 200 because the client settings layout had already streamed.
2026-10-13 — "No third-party brand names" applies to product copy, examples, prompts, comments and seed/fixture data. Kept: functional identifiers (the scraper's social/payment/app-store icon *skip* lists, the HTML term `apple-touch-icon`), required attributions (Pexels), and integration names in an integration context. Examples use reserved `.example` domains, since invented `.com` names may be real.
2026-10-13 — Studio's ownership rule: a URL must be the advertiser's website or a subdomain of it (exact label match; look-alike prefixes/suffixes refused). No website on file → generating from a URL is refused with a pointer to Settings → Advertisers; business-name-only generation (no site fetched) stays allowed. The free marketing generator (no advertiser, no login) is not gated — it has no ownership record to check against.
2026-10-13 — The retired `frontend/` folder (superseded by web/(marketing), no longer deployed) still contains the old example brand strings; deleting it is the owner's call.
2026-10-13 — Continuous delivery runs inside the API process (`DELIVERY_LOOP=true`), not a Render background worker — Render's worker services have no free tier. A Postgres advisory lock keeps it to one tick at a time; the compose `scheduler` runs the same tick for local stacks.
2026-10-13 — `SIM_SPEED` defaults to 1 (real time): a $50/day strategy spends ~$50 per real day and stats land on real dates. The plan allowed 60 (1 min = 1 h), but that inflates per-day spend 60× and dates race ahead; history comes from the 30-day backfill instead. A server that slept catches up the gap on wake (capped by `DELIVERY_MAX_CATCHUP_HOURS`, 48).
2026-10-13 — Admin tools are gated twice: `ALLOW_SIMULATION=true` *and* the user's email in `ADMIN_EMAILS`; otherwise 404. "Simulate N days" is scoped to the caller's own account so it can never fabricate history for real customers' campaigns.
2026-10-13 — Demo login defaults to `demo@adcraft-demo.com` (never emailed; reserved TLDs like `.example` are rejected by the login validator). Password is chosen at seed time.
2026-10-13 — Attribution and rollups rewritten as single `INSERT … SELECT` statements (proven equal to the originals by tests) because the per-row Python versions were too slow to run on every tick on a 0.1-CPU host.
2026-10-13 — Seeded channels that imitated real brands are renamed by an Alembic data migration (in place, ids kept) rather than a re-seed, which would regenerate households and orphan existing delivery data.
2026-10-13 — Ask Agent uses `claude-opus-5-5` at `medium` effort, non-streaming (the panel takes one JSON reply). `AGENT_EFFORT=low` trades depth for speed if replies feel slow.
2026-10-13 — When the agent can't reach the LLM, it shows the "unavailable" notice and help links rather than any templated advice — a template can't see the account, and the old one stated facts that were false for most users.
2026-10-13 — Agent proposals are limited to budget, max CPM, bidding mode and duplicating a strategy; anything else gets pointed to the right screen. `apply` enforces the same allow-list server-side.
2026-10-13 — Demo clean-up deletes whole accounts, not individual campaigns: test data lives in test sign-ups, and partial deletes leave half-configured accounts. It is a CLI that reports by default; we don't run destructive commands against production — the owner runs `--apply`.
2026-10-13 — Ask Agent runs on Groq's free tier (gpt-oss-120b) because the owner wants free hosting; Anthropic stays supported if a paid key is set. A Groq key placed in ANTHROPIC_API_KEY is used with Groq instead of failing.
