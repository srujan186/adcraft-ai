2026-10-09 — Full-suite flake fixed (surfaced by the capstone): test_studio_job_endpoint failed only in the full suite with "Event loop is closed". Root cause: background-task services (studio/audiences/creative_processing/simulator) bind `SessionLocal` at import from app.core.db — the production engine (pooled, dev DB), which conftest never overrode (it overrides only get_db). A pooled asyncpg connection is bound to the loop that opened it; TestClient uses a fresh loop per request, so a late test reusing a connection from an earlier, now-closed loop raised. Fix: conftest re-points those modules' SessionLocal at the NullPool test session, so background work runs against the test DB on the current loop (no cross-loop pool, no dev-DB side effects, production pooling unchanged). Also hardened run_studio_job's success-path job re-fetch with a None-guard (job deleted/cancelled mid-render), matching the error path.
